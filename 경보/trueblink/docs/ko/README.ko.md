# TrueBlink for SPHEREx (한국어 안내)

> 팀 내부용 한국어 문서입니다. 제출 페이지와 데모에 들어가는 글은 반드시 영어로 씁니다(영문 원본은 저장소 맨 위의 `README.md`).

## 무엇을 만드는 도구인가

TrueBlink는 NASA SPHEREx 적외선 영상을 같은 하늘 영역에 대해 시간 순서로 깜빡여(blink) 보여 주는 정적 웹 도구입니다. 좌표나 천체 이름을 넣거나 챌린지 대상 다섯 개(Barnard's Star, Epsilon Indi B, WISE 0855-0714, RW Aurigae, R Draconis) 중 하나를 고르면, 브라우저가 NASA 공개 아카이브에서 영상을 직접 읽어 옵니다. 움직이거나 밝기가 바뀌는 천체가 눈에 띄게 하는 것이 목적입니다.

### 핵심 아이디어

SPHEREx는 선형 가변 필터(linear variable filter)로 하늘을 봅니다. 검출기 위치에 따라 보는 파장이 다르고, 노출마다 하늘이 한 채널씩 옮겨 가므로 같은 별이라도 **노출마다 파장이 다릅니다**. 그래서 노출을 시간 순서대로 그냥 깜빡이면 별이 색 때문에 밝아졌다 어두워졌다 합니다. 변화가 아니라 색을 보는 셈입니다.

TrueBlink는 같은 것끼리 비교합니다. 방문(visit)마다 모든 방문에 공통으로 있는 분광 채널만 모아 한 장을 만들고, 모든 프레임에 날짜(호박색)와 파장(청록색)을 붙입니다. 변화량은 원래 검출기 픽셀에서 측광으로 잽니다.

우리 코드로 실제 픽셀을 시험했습니다(`scripts/audit/like-with-like.ts`, 2026-11-14). RW Aurigae 주변의 밝기가 일정한 별 6개를 노출 하나씩 시간 순서로 비교하면 보통 1.24배(최대 약 1.85배) 달라 보였고, 방문 사이에 같은 채널끼리 비교하면 3.1%였습니다. 한 검출기에서 방문의 모든 노출을 쌓은 영상은 이미 거의 균형이라 3.5%였지만, 노출을 40%만 골라 쌓으면 7.3%로 커졌습니다. 문제는 단일 노출을 깜빡이거나 날짜마다 채널 구성이 다를 때 생깁니다.

### 두 가지 모드

- **Explore(탐색) 모드**: 일반 사용자용. 대상별 카드(무엇인지, 무엇을 볼지, 세 단계 안내(WISE 0855-0714는 네 단계), 카탈로그 값과의 비교), 기기 잡음(artefact) 설명 카드.
- **Research(연구) 모드**: 시퀀스 종류, 파장 묶음, 스트레치, 오버레이(Gaia 별, 예상 경로, 플래그, SkyBoT 소행성). 탭은 Frames(노출 목록), Measure(측광·스펙트럼·광도곡선·같은 파장 비율·고유운동. 밝기 비는 0.75-2.4 µm와 2.4-5.0 µm로 나누고 검출기별로도 보여 줌), Overlays(플래그·Gaia 별), Asteroid(실제 SPHEREx로 잰 소행성 4개: Hygiea, Dembowska, Eros, Kollaa), Provenance(사용한 파일 목록, CSV·JSON 내보내기)입니다.
- **차가운 천체 필터(영문 화면: Cold-object filter)**: 시퀀스 목록에 있고, URL은 `seq=coldFilter`, WISE 0855-0714 미션의 3단계입니다. 방문마다 4.2-4.8 µm 노출을 쌓은 영상에서 3.82-4.05 µm 노출을 쌓은 영상에 배율(기본은 레일리-진스 값, 약 0.77)을 곱해 뺍니다. 보통 별은 지워지고, 메테인 흡수 때문에 4.2 µm 너머에서 주로 빛나는 아주 차가운 갈색왜성은 남습니다. 두 파장대 모두 노출이 3장 이상인 방문만 프레임이 되므로 WISE 0855-0714는 방문 4번 중 2번(2025-11-07, 2026-05-02)만 나옵니다. 이때 대상의 S/N은 26.9와 32.9(4.2-4.8 µm만 쌓으면 42.4와 59.9)이고, G = 16.3 별은 밝기의 약 2-17 %만 남습니다(더 어두운 별은 잡음에 묻힘). 화면에 밝게 남는 것은 WISE 0855뿐이고, 두 프레임 사이에 서쪽으로 움직입니다. 색으로 고르는 방법이지 정체를 밝혀 주지는 않습니다. Epsilon Indi B 같은 T형 왜성은 빛이 4 µm 근처에 몰려 있어 오히려 어둡게 나오고, RW Aurigae 같은 먼지에 싸인 어린 별은 밝게 남습니다. 밝거나 포화된 별 주변에는 찌꺼기가 남습니다.
- **전천 지도와 3D 쌓기**: SPHEREx 전천 지도(1년 평균이라 변화는 못 보여 줌)와, 프레임을 시간이나 파장 축으로 쌓아 보는 3D 보기.

### 작동 방식

- 픽셀은 공개 S3 버킷 `nasa-irsa-spherex`에서 브라우저가 HTTP Range 요청으로 필요한 부분만 읽습니다. 파일 하나가 66 MB여도 실제로는 수백 KB만 받습니다.
- 노출 검색(IRSA SIA)만 CORS 헤더가 없어서 작은 중계 함수(`functions/api`)를 거칩니다.
- 사진 한 장은 증거가 아닙니다. WISE 0855 영역에서 새 천체처럼 보인 점은 노출 한 장에만 찍힌 우주선(cosmic ray) 흔적이었습니다. 지금은 방문별 영상을 만들 때 다른 채널과 동떨어진 값 하나를 걸러 냅니다.
- 노출 검색 중계는 `GET /api/sia` 하나만 받습니다.
- 챌린지 대상 다섯 개는 노출 목록과 픽셀 묶음(IMAGE·FLAGS, `public/presets/<id>.bundle.*`)을 미리 구워 두어서 중계나 아카이브가 죽어도 열립니다. 첫 프레임은 1초 안팎, 측정은 3-6초면 끝납니다. 다른 위치, 3분각보다 넓은 시야, VARIANCE·ZODI 면은 S3에서 실시간으로 읽고 브라우저(IndexedDB)에 저장합니다. 5분각 시야(노출 약 330장)는 시험한 회선에서 40초쯤 걸렸습니다.
- "Then and now(그때와 지금)"의 AllWISE 영상은 2026-11-14에 CDS 영상 서비스가 멈춰서 IRSA의 HiPS 타일로 대신 읽습니다. 같은 이유로 2MASS 영상은 지금 나오지 않습니다.

## 실행 방법

Node.js 20.19 이상이 필요합니다(개발과 시험은 Node 26으로 했습니다).

```bash
cd trueblink
npm install
npm run dev      # http://localhost:5173 (개발 중에는 Vite가 /api/sia를 IRSA로 넘겨 줌)
npm test         # 단위 테스트 (오프라인)
npm run build    # 타입 검사 후 dist/ 생성
```

실제 아카이브에 붙는 테스트는 `LIVE=1 npx vitest run tests/live`, 프리셋(노출 목록과 픽셀 묶음) 갱신은 `npm run bake`입니다. 실제 자료로 측정 모듈을 돌려 보려면 `npx tsx scripts/measure-check.ts barnard`.

배포는 `docs/DEPLOY.md`(영문, 단계별)를 따르세요. 과학 설명은 `docs/SCIENCE.md`, 제출 페이지 문안은 `docs/SUBMISSION.md`, 마감 전 할 일은 같은 폴더의 `TEAM_GUIDE.ko.md`에 있습니다.
