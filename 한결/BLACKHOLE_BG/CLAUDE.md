# SPHEREx Explorer — 메인 화면 블랙홀 배경

NASA Space Apps 2026 (Planet X and SPHEREx) 해커톤 프로젝트 「방구석 천문학자」의 메인 화면.
배경은 이목 끌기용이고 핵심 기능이 아님. 블랙홀은 메인 화면(`/`)에만 있고, 세부 화면(#blink 등)으로 가면 시뮬레이션을 멈춤.

## 현재 결정 (2026-11-14 사용자 확인)
**실시간 체험 우선: 방정식 기반 근사 모델을 쓰고 정확도 한계를 명시.**
메인은 PN → EOB → NR 피팅 링다운을 사용한다. GPU BSSN은 물리 자격 검증 미통과이며 메인에서 로드하지 않는다. 과거 HANDOFF_NR.md·NR_HANDOFF.md(폐기된 계획)보다 이 결정과 HANDOFF_CODEX.md의 현재 상태를 우선한다. Git 저장소가 아니며 수정 전 파일은 backups/codex-2026-11-14/에 보존했다.

## 실행
- 로컬 서버로 열 것 (file://로 열면 배경 webp를 못 읽음): `python3 -m http.server 8765 --bind 127.0.0.1` → http://127.0.0.1:8765
- 테스트: `node --test tests/` (모두 통과해야 함)

## 파일
- `bbh-physics.js` — 순수 물리 함수 (DOM 없음). PN 운동방정식, 슈바르츠실트 휨각, NR 피팅, 가스 원반 마찰
- `bbh-eob.js` — 2PN EOB 해밀토니안 + 선도 준원궤도 복사 토크, RK4, Buonanno–Damour 2000 원문 식 2.11·2.14–16 대조
- `bbh-nr.js`, `bbh-nr-id.js` — 별도 실험용 GPU BSSN·BY 초기자료. 메인에서 로드하지 않고 `bbh-sim.js`에도 연결 코드가 없다(2026-11-14 3차에서 미완성 연결 경로 제거). canStart()는 검증 실패 때문에 false. 자체 페이지 `tests/gpu/nr-selftest.html`에서만 실행.
- `bbh-sim.js` — N체(≤4) 적분기 (RK4, 프레임과 무관한 물리 시간 간격), 병합·지평선 융합, 중력파 Q̈ 버퍼
- `gravity-hero.js` — 렌더링(WebGL2 한 번의 draw call)·입력·화면 연출
- `index.html` — 메인 화면, 파형 패널, '모델·출처' 패널
- `sky_spherex_stars.webp` — SPHEREx 전천 별 지도(SPHEREx_StarsRGB.tif, 4160×2340 몰바이데)를 은하 좌표 CAR 파노라마로 재투영: 8192×2731, 경도 360° × 위도 ±60°, l=0 중앙, l은 왼쪽으로 증가. 파일이 없으면 절차 생성 은하로 대체
- 선명도 규칙: 화면 폭에 하늘 ~140°(원본 픽셀 ≈ 화면 CSS 픽셀 1:1), devicePixelRatio 최대 2, 고정 상한 300만 렌더 픽셀. 시야를 좁히면 원본보다 확대돼 흐려짐
- 새 유입: `_spawn`에서 새 물체의 전역 렌즈를 즉시 켜지 않는다. `arrival` 광학 가중치를 벽시계 2초의 quintic easing으로 0→1 전환하며, 그림자가 보이기 전에 전환할 수 있도록 시작 위치를 화면 밖으로 더 물린다. 실제 질량·위치·기존 시뮬레이션/파형 시계는 이 전환으로 변경하지 않는다. 유입은 유한 화면의 연출 경계 조건이며 GR의 질량 생성 계산이 아니다.
- 연속성 규칙: 렌더 해상도는 실행 중 바꾸지 않음, 슬로모션은 0.15배까지·지수적으로 변화, 누적 병합 4회인 잔해는 병합 연결이 끝나면 퇴장을 예약하고 약 6초 동안 전체 광학 효과를 함께 이동·페이드한다

## 인터랙션 (이것만)
1. 블랙홀 드래그 (놓으면 가까운 상대의 병진 속도를 이어받는 배치 모드; 포인터 보간 속도를 발사 속도로 쓰지 않음)
2. 가까운 블랙홀은 중력으로 병합, 끌어서 겹쳐도 병합, 병합 후 중력파
3. 빈 곳 클릭 → 약한 파동 (연출)
4. 블랙홀은 떠다니며 렌즈로 배경을 휘게 함
5. 크기 랜덤, 최대 3개, 하나가 사라지면 4초 뒤 가장자리에서 새로 등장
- 크기와 무관하게 잔해의 누적 병합 이력(`mergerCount`)이 4회 이상이고 병합 연결이 끝나면 가까운 가장자리로 약 6초에 걸쳐 퇴장. 1~3회에는 자동 퇴장하지 않는다. 새 잔해의 이력은 양쪽 이력 중 큰 값 + 1이며 PN/EOB/드래그 복원에서 유지한다. 새 유입 객체는 먼저 입장하도록 한다. 퇴장 객체의 추가 포획을 막고 상호작용을 1초 동안 감쇠한다. 물리적 반동이 아닌 배경 수명 관리다.
- 블랙홀 생성 버튼, 키보드, HUD 추가 금지

## 물리 고증 원칙 (가장 중요)
- 정해진 궤도를 재생하지 말 것. 모든 움직임은 운동방정식 적분에서 나와야 함.
- 모든 모델에 라벨: `LECTURE`(강의 내용) / `ADDED MODEL`(강의 밖 근사·피팅) / `GR EXACT` / `ILLUSTRATIVE`(예시 연결) / `VISUAL METAPHOR`(과장 연출). index.html '모델·출처' 패널과 일치시킬 것.
- 계수는 반드시 원 문헌 대조 + 테스트로 검증. 기억에 의존하지 말 것 (실제로 B₂PN의 41ν → 41/2 ν 오류를 테스트가 잡음).
- GPU BSSN 실험은 단일 그림자 유지·구속식 수렴·쌍성 병합 자격 검증 미통과. 실시간 메인은 근사 모델이며 3M 안쪽은 NR 피팅 + 광학적 예시 연결이다. 그림자와 사건/겉보기지평선을 혼동하지 않는다. 정확도 백분율을 주장하지 않는다.

### 현재 모델
- 중력: 조화 좌표 질량중심계 상대가속도 a = −(GM/r²)[(1+A)n + Bv], 뉴턴 + 1PN + 2PN(보존) + 2.5PN(복사 반작용). 출처 Blanchet LRR 17, 2 (2014), Mirshekari arXiv:1308.5240. 1PN·2PN은 12M→6M에서 감쇠.
- EOB: 접근 중인 비고정 쌍은 8M 안쪽에서 가능한 경우 EOB로 전환. A=1−2/r+2ν/r³, D=1−6ν/r², B=D/A. F_j=−(32/5)ν sign(Ω)|Ω|^(7/3), F_r=0. 선도 준원궤도 복사이며 정밀 SEOBNR가 아니다. PN→EOB 연결은 위치·속도를 맞춘 좌표 근사이며 canonical 변환이 아니다. EOB 중 제3체는 질량중심의 근사적 중력 상호작용. 출처: https://arxiv.org/abs/gr-qc/0001013
- 렌즈: 슈바르츠실트 측지선 정확한 휨각 α(b) 테이블, 하늘 구면 회전. 그림자 b_c = 3√3M. 여러 개는 휨 합산(근사). 병합 말기에는 총질량 단극으로 연결: Σα(M_i/b) ≠ α(ΣM_i/b). 최종 Kerr 렌즈는 미구현. 그림자와 렌즈는 동일한 구면 각거리 θ 및 병합 광학장 S를 사용한다. x=S^(1/4)가 1에 닿는 곳을 포획 경계와 강한 휨각 경계로 함께 사용한다. 독립적인 화면 원 마스크를 다시 추가하지 않는다. 단일체는 정확한 Schwarzschild 휨각, 쌍성장은 명시적 광학 근사다.
- 포획: 함께 도는 가스 원반 마찰 (ENV: rEnvM 30, β 0.4, q 0.94, κ 5, 6.5M 안쪽 끔). 원반 회전 방향은 진입 시 고정.
- 질량 효과: 동역학적 마찰 γ ∝ 질량, 떠다님 속도 ∝ 1/√m, 다른 블랙홀 중력이 느껴지면(2~8 px/s²) 떠다님 꺼짐.
- 병합: r < 3M에서 궤도 적분 종료 → 그림자 두 성분이 위치·각속도·안쪽 속도를 이어받아 융합 (ILLUSTRATIVE). 공통 지평선 계산이 아니다.
- 잔해·링다운 (질량/스핀 피팅은 비회전·준원궤도 보정 범위, 편심/정면 충돌은 외삽; EOB 잔해 스핀은 가용 canonical J/M_f² 이하로 제한): E_rad Husa+2016 (arXiv:1508.07250 eq 3.7), 스핀 Pan+2011 (PRD 84 124052 eq 29b), QNM Berti·Cardoso·Will 2006 (PRD 73 064030).
- 중력파: 궤도 Q̈ = μ(ax+2vv+xa)를 1/240초마다 기록, t − r/c 지연, 횡방향 변위 ∝ 1/r, ×12 과장. 메인 히스토리 4096 샘플(약 17초), 파형 패널은 방출 지점 시간이고 화면 변위는 t−r/c 지연이다.
- 화면 단위 (창 크기 변경 시 R1·c·질량·물리 시계 유지, 카메라 900px 하드 전환 금지): c ≈ 450 px/s, 하늘 화면 너비 ≈ 140°, 그림자 반지름 R1 ≈ 11px × 질량. 궤도가 빠르면 전체 슬로모션 (OMEGA_REF 4).

## 성능 규칙
- 실제 렌더 프레임당 draw call 1회. 평상시 30fps, 드래그·빠른 궤도·유입·퇴장·클릭 파동 중 최대 60fps. 물리 시계는 렌더 생략과 독립. 배경 텍스처가 준비되기 전 물리/파형 진화를 시작하지 않는다.
- 렌더 텍스처·유니폼과 힘 계산 임시 배열 재사용, 큰 프레임 할당 금지
- 리사이즈 시 전체 계와 GW 소스를 동일하게 카메라 평행이동한다. 상대 거리·속도·질량은 보존하고 화면이 좁아졌다고 즉시 바디를 삭제하지 않는다.
- dt는 1/30초로 제한, 자동 해상도 전환 금지; 리사이즈 마지막 변경 160ms 후 버퍼 재할당과 즉시 redraw. 버퍼 x/y 각각 CSS 크기로 변환
- 탭 숨김·화면 밖·세부 화면이면 정지, prefers-reduced-motion이면 자동 물리 진화·파동을 멈추고 드래그할 때만 상태 갱신

## 추가 회귀 검사와 실험 NR
- 현재 Node 검사 48개: `node --test tests/`.
- `tests/browser.html`: 실제 렌더러의 비스듬한 접근·정면·완전 겹침·리사이즈·병합 끝 WebGL 픽셀 비교. 메인 HUD 추가 없이 테스트 페이지에서 검사한다.
- `node tests/gpu/run.mjs operators '[]'`: BSSN 공간 연산자와 구속식 차분 수렴만 검사. 장기 진화·물리적 병합 검증과 다르다.
- GPU runner는 예외·병합 미달·단일 그림자 ±5% 실패 시 비정상 종료한다. NaN이 없다는 이유로 통과시키지 않는다.
- NR `conformalW`, `precollapsed`, `cako`는 실험 옵션이며 기본값 false. W 미분은 χ=W²의 연쇄법칙, CAKO는 Etienne 2024 eq.20. https://arxiv.org/abs/2404.01137
- `constraints()`의 H/M/Γ 절대 오차와 격자 수렴을 본다. relativeH는 항 크기로 정규화한 진단값이지 정확도 백분율이 아니다.
- 펑처 좌표 거리 <1M와 χ<0.12 광선 중단은 게이지 의존 휴리스틱이며 공통 지평선의 증거가 아니다. 고정 슬라이스 광선추적도 동적 시공간의 정확해가 아니다.
- 과거 sim의 NR 통합 함수(η=0.25 고정, 궤도 방향 소실)는 제거했다(원본: backups/claude-2026-11-14-round3/). 다시 연결하려면 질량비·방향 연결, 실패 시 두 바디 복원, 파형·렌즈·시간 진행과 실제 지평선 판정을 새로 설계·검증해야 한다.
- EOB 구성 블랙홀을 잡으면 그 순간 위치·속도로 PN 바디를 복원하고 사용자 외력으로 이어간다.

## 두 번째 화면 정렬·수명 검증 (2026-11-14)
- `node --test tests/`: 52개. 방출 t=0 샘플, EOB 병합 시계, 조용한 파형 슬롯 재사용, 32방향 배치 후 포획, 퇴장 중 추가 병합 방지와 단조 광학 연결을 포함한다.
- `TEST_PAGE=tests/gpu/optics.html node tests/gpu/run.mjs optics '[]'`: 실제 WebGL 34개 상태. 단일체 구면 포획 경계의 독립 CPU 해석값, 이동, 병합 단계·각도, GW 변위에서 그림자/렌즈 경계 일치 검사.
- 같은 명령의 `waves '[]'`: 실제 셰이더에서 파면 안/밖 및 방출 종료 3.6초 후 남은 파동 7점을 읽어 t−r/c 도달 시점 검사.
- `node tests/background-stress.cjs 3600`: 고정 난수로 1시간·108000프레임의 CPU 수명 검사. population ≤3, 유한 상태, 퇴장, 4회 이전 조기 퇴장 방지. GPU 성능 검사와 다르다.

- 이전 정지 프레임의 최종 전환 검사만으로 이동/병합 정렬이 검증됐다고 하지 않는다.
