# 방구석 천문학자 · SPHEREx Sky Lab 입장 화면

`v2.1.0` 통합 사이트의 홈페이지입니다. 한결의 블랙홀 배경을 유지하고, **플라네타리움 입장** 버튼으로 중선의 천체 지도에 연결합니다. 플라네타리움에서 천체를 선택하면 해당 좌표를 경보의 분석 작업실에 전달할 수 있습니다.

- `./planetarium/`: 플라네타리움
- `./planetarium/?view=allsky`: 전천 지도
- `./analysis/`: SPHEREx 분석 작업실

통합 사이트는 상위 `v2.1.0` 폴더의 실행 안내를 따르세요. 빌드 시 이 홈페이지의 실행 파일이 사이트 루트에 복사됩니다. 이 폴더만 단독으로 서빙하면 배경 화면은 볼 수 있지만, 다른 두 프로젝트로 가는 링크는 통합 빌드에서만 연결됩니다.

기존 데모의 빈 세부 화면과 배경 이미지 드롭 기능은 홈페이지에서 제거했습니다. 블랙홀 배경은 화면을 떠나거나 탭을 숨기면 멈추고, 시스템의 모션 줄이기 설정을 따릅니다. `demo.html`은 기존 독립 데모로 남아 있습니다.

## 블랙홀 배경

실시간 PN/EOB 기반 블랙홀 병합 배경. 완전한 수치상대론 시뮬레이션이 아니며 쌍성 광학과 최종 그림자 연결은 근사입니다.

## 실행

이 폴더에서 `python3 -m http.server 8765` 실행 후 http://localhost:8765 접속.

## 검증

`node --test tests/` — 52개 검사. 상세 결과는 tests/results/respawn-validation.md 참조.

4회 병합 후 부드러운 퇴장, 2초 새 렌즈 유입 연결 적용.
