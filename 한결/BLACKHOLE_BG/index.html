이 배경은 무엇을 계산하나요

  • 움직임 모든 블랙홀의 운동방정식을 매 순간 적분해요(RK4, 프레임과 무관한 물리 시간 간격). 정해진 궤도를 재생하지 않아요.
  • 먼 거리의 중력 아인슈타인 방정식을 두 점질량에 대해 v²/c²로 전개해 푼 후-뉴턴 운동방정식(조화 좌표, 질량중심계): 뉴턴 + 1PN + 2PN(보존) + 2.5PN(중력파 반작용). 계수는 Blanchet LRR(2014)과 Mirshekari(2013)로 대조했고, 2PN 보존 에너지가 실제로 보존되는지, 원궤도 진동수가 2PN 급수와 맞는지 테스트로 확인해요. PN 구간의 1PN·2PN은 12M→6M에서 감쇠하며, 접근 중인 쌍은 가능한 경우 8M 안쪽에서 EOB로 전환해요 ADDED MODEL
  • 단일 블랙홀 렌즈 슈바르츠실트 해의 널 측지선을 수치 적분한 휨각 α(b)와 포획 경계 b = 3√3M를 사용해요. 비회전·고립 블랙홀 식이며, 최종 잔해의 Kerr 렌즈는 구현하지 않았어요 GR EXACT
  • 여러 블랙홀의 렌즈 그림자와 휨각이 같은 구면 각거리·포획 경계를 사용해요. 병합 중에는 두 성분과 총질량 단극을 같은 광학장으로 연결해요. 실제 쌍성 계량의 광선추적이나 사건지평선은 아니에요 ILLUSTRATIVE
  • 붙잡힘·나선 가스가 있는 환경을 가정한 함께 도는 원반 마찰이에요. 포획을 빠르게 보이도록 세기를 강화했으며 진공 쌍성의 보편적 거동은 아니에요. EOB 구간에서는 이 마찰을 끄고 복사 토크를 사용해요 ADDED MODEL
  • 무거운 쪽은 덜 움직임 은하 별들과의 동역학적 마찰(찬드라세카르, 제동 ∝ 질량)로 무거운 블랙홀은 거의 멈추고 가벼운 쪽이 끌려와요. 혼자 있는 블랙홀의 느린 떠다님(속도 ∝ 1/√질량)은 다른 블랙홀의 중력이 느껴지기 시작하면 사라져서, 다가오는 쌍을 떼어놓지 않아요 ADDED MODEL
  • 강한 장의 궤도·플런지 2PN EOB 해밀토니안: A = 1−2/r+2ν/r³, D = 1−6ν/r². 복사에 의한 선도 원궤도 각운동량 손실을 더해 RK4로 적분해요. PN→EOB 위치·속도 연결은 좌표 근사이며, 정밀 SEOBNR 파형 모델은 아니에요 ADDED MODEL
  • 3M 이후의 병합 그림자 궤도 적분을 끝내고 위치·각속도·안쪽 속도를 이어받는 연속 광학 연결을 사용해요. 두 검은 영역은 그림자의 근사 표현이며, 공통 겉보기지평선을 푼 결과는 아니에요 ILLUSTRATIVE
  • 단계 구분 인스파이럴 → 병합 → 링다운 LECTURE p.10
  • 잔해·링다운 복사 에너지 Husa et al. 2016, 최종 스핀 Pan et al. 2011, l=m=2 준정규모드 Berti·Cardoso·Will 2006의 피팅식이에요. 질량·스핀 피팅은 비회전·준원궤도 쌍성에 대해 보정됐어요. 편심·정면 충돌은 보정 범위 밖 외삽이고, EOB 잔해 스핀은 주어진 각운동량을 넘지 않도록 제한해요 ADDED MODEL
  • 시공간 일렁임 실제 궤도에서 계산한 사중극 Q̈를 지연시간 t − r/c로 읽어, 그 자리의 변형률(∝ 1/r)만큼 별빛을 진행 방향에 수직으로 밀어요. 멀어질수록 약해지고, 블랙홀 바로 옆(근거리장)에서는 표시하지 않아요. 그림자도 같은 변위 좌표에서 샘플해요. 화면의 2차원 변형은 실제 관측 영상이 아닌 시각적 비유이며 변위는 ×12 과장해요. 빈 곳 클릭 파동도 연출 VISUAL METAPHOR
  • 큰 블랙홀 퇴장 렌즈 영역이 화면의 18%를 넘거나 그림자 반지름이 짧은 화면 변의 7%를 넘으면 약 6초에 걸쳐 가장 가까운 가장자리로 퇴장해요. 추가 포획을 멈추는 배경 화면 관리이며, 중력파 반동을 계산한 물리적 방출은 아니에요 ILLUSTRATIVE
  • 화면 단위 빛의 속도 약 450 px/s, 하늘은 화면 너비에 약 140°. 궤도가 빨라지면 전체 물리 시간을 부드럽게 늦춰요. 창 크기를 바꿔도 광속과 질량 단위는 유지해요 ILLUSTRATIVE
  • 수치상대론과의 구분 GPU BSSN 실험 코드는 별도로 존재하지만, 단일 블랙홀 그림자 유지와 구속식 수렴·쌍성 병합 검증을 통과하지 못해 이 화면에서는 실행하지 않아요. 이 화면은 실시간 PN/EOB 근사이며 정확도 백분율을 보장하지 않아요.
